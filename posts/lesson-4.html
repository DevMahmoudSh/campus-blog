كيفية كتابة كود نظيف (Clean Code) وتجنب الأخطاء الشائعة

            
في هذا الدرس سنتعلم أساسيات كتابة أكواد قابلة للقراءة والصيانة، مع أمثلة عملية جاهزة للاستخدام في مشاريعك القادمة.

        


        
        

            
            
كتابة الكود لا تقتصر فقط على جعل البرنامج يعمل، بل تمتد لتشمل جعل الكود مقروءاً وقابلاً للتطوير لك ولزملائك في المستقبل. يُعتبر مصطلح الكود النظيف من أهم المفاهيم التي يجب على أي مبرمج إتقانها.


            
1. تسمية المتغيرات بشكل واضح ومفهوم

            
تجنب الأسماء المختصرة والغامضة. يجب أن يكون اسم المتغير دالاً بشكل واضح على البيانات التي يحملها.

            
            

// ❌ مثال على كود سيء
let d = 86400; // ماذا يعني حرف الـ d؟

// ✅ مثال على كود نظيف
const SECONDS_IN_A_DAY = 86400;
let elapsedDays = 3;
let totalSeconds = elapsedDays * SECONDS_IN_A_DAY;
            


            
2. تصميم الدوال (Functions)

            
من أهم قواعد كتابة الدوال النظيفة:

            
    
                
  • يجب أن تقوم الدالة بمهمة واحدة فقط.
    • 
                
  • لا تجعل الدالة طويلة جداً (يفضل ألا تتجاوز 20-30 سطراً).
    • 
                
  • استخدم أسماء أفعال واضحة للدوال مثل getUserData أو calculateTotal.
    • 
            


            

<?php
// دالة تقوم بمهمة واحدة بشكل واضح ومباشر
function calculateDiscount($price,$discountPercentage) {
    if ($price <= 0 \vert{}\vert{}$discountPercentage < 0) {
        return 0;
    }
    return $price - ($price * ($discountPercentage / 100));
}

echo calculateDiscount(100, 20); // النتيجة: 80
?>
