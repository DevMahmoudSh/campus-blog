ملخص محاضرة: أوامر تعديل الجداول (ALTER TABLE) في MySQL

يُعتبر أمر ALTER TABLE أحد أهم أوامر لغة تعريف البيانات (DDL)، ويُستخدم لتعديل الهيكل البنائي لجدول موجود مسبقاً (إضافة، تعديل، أو حذف الأعمدة والقيود) دون المساس بالبيانات المخزنة داخله.

1

أولاً: القاعدة الذهبية لترتيب تعريف العمود

سواء كنت تنشئ جدولاً جديداً (CREATE) أو تضيف عموداً (ALTER)، فإن الترتيب القياسي لخصائص العمود يكون كالتالي:

اسم العمود ← نوع البيانات ← NOT NULL ← DEFAULT ← AUTO_INCREMENT ← UNIQUE ← CHECK ← PRIMARY KEY ← FOREIGN KEY

مثال تطبيقي:

Role VARCHAR(20) NOT NULL DEFAULT 'Student'
2

ثانياً: إدارة الأعمدة (إضافة، تعديل، حذف)

تُعد عمليات التعامل مع الأعمدة الاستخدام الأكثر شيوعاً لأمر ALTER TABLE. يوضح الجدول التالي الفروقات الجوهرية بين أوامر التعديل (وهو سؤال شائع في الاختبارات):

العملية الكلمة المفتاحية هل يتطلب كتابة نوع البيانات؟ مثال برمجي (ALTER TABLE Employees ...)
إضافة عمود ADD نعم ADD Salary DECIMAL(10,2) AFTER Name;
حذف عمود DROP COLUMN لا DROP COLUMN Email;
تعديل النوع/الخصائص فقط MODIFY نعم MODIFY Name VARCHAR(100) NOT NULL;
تغيير الاسم والنوع معاً CHANGE نعم (الاسم القديم ثم الجديد ثم النوع) CHANGE Name FullName VARCHAR(100);
تغيير الاسم فقط (حديث) RENAME COLUMN لا (MySQL 8.0+) RENAME COLUMN Name TO FullName;
3

ثالثاً: التعامل مع قيد الفراغ (NOT NULL) والقيم الافتراضية

يتم التحكم في إجبارية الحقل عن طريق أمر MODIFY بإعادة تعريف العمود:

إضافة قيد عدم الفراغ (NOT NULL)

ALTER TABLE Employees MODIFY PhoneNumber VARCHAR(20) NOT NULL;
⚠️

تنبيه عملي: سيفشل هذا الأمر إذا كان الجدول يحتوي مسبقاً على سجلات فارغة (NULL) في هذا العمود. الحل هو تحديث البيانات القديمة أولاً بأمر UPDATE لملء الفراغات، ثم تطبيق ALTER.

إلغاء قيد (NOT NULL) والسماح بالفراغ مجدداً

ALTER TABLE Employees MODIFY PhoneNumber VARCHAR(20) NULL;

ضبط أو حذف القيمة الافتراضية (DEFAULT)


-- إضافة قيمة افتراضية
ALTER TABLE Employees ALTER COLUMN Status SET DEFAULT 'Active';

-- حذف القيمة الافتراضية
ALTER TABLE Employees ALTER COLUMN Status DROP DEFAULT;
4

رابعاً: إدارة القيود والمفاتيح (Constraints & Keys)

تُستخدم القيود لضمان سلامة البيانات وترابط الجداول. يفضل دائماً إعطاء اسم مميز للقيد (CONSTRAINT name) ليسهل حذفه لاحقاً.

نوع القيد أمر الإضافة (ADD) أمر الحذف (DROP)
المفتاح الأساسي (Primary Key) ADD PRIMARY KEY (ID); DROP PRIMARY KEY;
المفتاح الأجنبي (Foreign Key) ADD CONSTRAINT fk_dept FOREIGN KEY (DeptID) REFERENCES Depts(ID); DROP FOREIGN KEY fk_dept;
عدم التكرار (Unique) ADD CONSTRAINT uq_phone UNIQUE (Phone); DROP INDEX uq_phone;
الشرط المنطقي (Check) ADD CONSTRAINT chk_age CHECK (Age >= 18); DROP CHECK chk_age;
الفهارس (Indexes - لتسريع البحث) ADD INDEX idx_name (Name); DROP INDEX idx_name;
💡

خيارات الربط المتقدمة للمفتاح الأجنبي: يمكن إلحاق جملة ON DELETE CASCADE أو ON UPDATE CASCADE عند تعريف المفتاح الأجنبي لضمان حذف أو تحديث السجلات المرتبطة تلقائياً عند حذف أو تحديث السجل الأب.

5

خامساً: كيف تكتشف اسم القيد لحذفه؟

إذا نسيت اسم القيد (مثل اسم الـ Foreign Key) وتريد حذفه، يمكنك استخراجه بطريقتين:

الطريقة السريعة (عرض كود إنشاء الجدول)

SHOW CREATE TABLE Employees;

الطريقة المنهجية (الاستعلام من قاموس البيانات)


SELECT CONSTRAINT_NAME, CONSTRAINT_TYPE 
FROM information_schema.TABLE_CONSTRAINTS 
WHERE TABLE_NAME = 'Employees';
6

سادساً: أوامر متقدمة وإعدادات الجدول

مهارات إضافية تميز الطالب المتقدم ومهندس قواعد البيانات:

تغيير اسم الجدول بالكامل

ALTER TABLE Employees RENAME TO Staff;

تعديل بداية الترقيم التلقائي

ALTER TABLE Employees AUTO_INCREMENT = 1000;

توحيد ترميز الحروف (لدعم العربية والرموز)

ALTER TABLE Employees CONVERT TO CHARACTER SET utf8mb4;

الأعمدة المحسوبة تلقائياً (Generated Columns)

ALTER TABLE Employees ADD AnnualSalary DECIMAL(10,2) AS (Salary * 12) VIRTUAL;

تعديل الجداول الضخمة دون إيقاف النظام (Zero Downtime)

ALTER TABLE Employees ADD Phone VARCHAR(20), ALGORITHM = INPLACE, LOCK = NONE;

دمج عدة أوامر معاً (لتقليل الحمل على الخادم)


ALTER TABLE Employees
ADD Age INT,
MODIFY Name VARCHAR(120) NOT NULL,
DROP COLUMN TempColumn;
