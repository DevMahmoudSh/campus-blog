التمهيد: إعداد بيئة العمل

قبل البدء في تنفيذ العمليات، سنقوم بإنشاء جدول باسم employees (الموظفين) لنطبق عليه جميع الشروحات والأكواد القادمة:

SQL
CREATE TABLE employees ( id INT AUTO_INCREMENT PRIMARY KEY, name VARCHAR(100) NOT NULL, department VARCHAR(50), salary DECIMAL(10, 2) );
1

أولاً: جميع حالات الإضافة (INSERT) في MySQL

تُستخدم تعليمة INSERT لإدخال بيانات جديدة إلى الجدول. في الإصدارات الحديثة من MySQL، لدينا 8 طرق وحالات مختلفة للإضافة:

1. الإضافة القياسية (تحديد الأعمدة والقيم)

وهي الطريقة الأكثر أماناً ووضوحاً، حيث نحدد أسماء الأعمدة، ثم نمرر القيم بنفس الترتيب.

SQL
INSERT INTO employees (name, department, salary) VALUES ('أحمد', 'IT', 5000.00);

2. الإضافة المختصرة (بدون تحديد الأعمدة)

وهنا نكتب القيم مباشرة دون كتابة أسماء الأعمدة.

⚠️

شرط هام جداً: عند استخدام هذه الطريقة، يجب أن يكون عدد القيم المدخلة مساوياً لعدد الأعمدة في الجدول، وبنفس الترتيب تماماً. نستخدم NULL لعمود id ليقوم بزيادة الرقم تلقائياً.

SQL
INSERT INTO employees VALUES (NULL, 'خالد', 'HR', 4000.00);

3. الإضافة المتعددة (Bulk Insert)

لتحسين أداء قاعدة البيانات وتوفير الوقت، يمكنك إضافة عدة سجلات دفعة واحدة في استعلام واحد.

SQL
INSERT INTO employees (name, department, salary) VALUES ('سارة', 'HR', 4500.00), ('عمر', 'Sales', 4800.00);

4. الإضافة باستخدام طريقة SET

هذه الطريقة خاصة بـ MySQL، وهي أنيقة جداً وتسهل قراءة الكود، حيث تشبه طريقة كتابة التحديث.

SQL
INSERT INTO employees SET name = 'محمود', department = 'IT', salary = 6000.00;

5. النسخ من جدول لآخر (INSERT INTO ... SELECT)

نستخدمها عندما نريد أخذ بيانات من جدول وإضافتها لجدول آخر (مثلاً لعمل أرشيف).

SQL
INSERT INTO employees_archive (name, department, salary) SELECT name, department, salary FROM employees WHERE department = 'Sales';

6. الإضافة الآمنة مع تجاهل الأخطاء (INSERT IGNORE)

إذا حاولت إدخال موظف موجود مسبقاً (لديه نفس المعرف ID مثلاً)، فلن يتوقف النظام ولن يُظهر رسالة خطأ، بل سيتجاهل هذا السطر ويكمل إضافة باقي السجلات.

SQL
INSERT IGNORE INTO employees (id, name, department) VALUES (1, 'أحمد', 'IT');

7. الإضافة أو التحديث (ON DUPLICATE KEY UPDATE)

إذا كان السجل غير موجود سيتم إنشاؤه، وإذا كان موجوداً بالفعل سيقوم النظام بتحديثه ببياناتك الجديدة.

SQL
INSERT INTO employees (id, name, salary) VALUES (1, 'أحمد', 5500.00) ON DUPLICATE KEY UPDATE salary = 5500.00;

8. إضافة القيم الافتراضية فقط

إذا كانت جميع أعمدة الجدول تحتوي على قيم افتراضية (DEFAULT)، يمكنك إضافة صف يعتمد على هذه القيم فقط.

SQL
INSERT INTO employees () VALUES ();
2

ثانياً: التحديث (UPDATE) والشروط المعقدة

🚨

تحذير خطير: يجب دائماً استخدام شرط WHERE مع تعليمة UPDATE. إذا لم تكتبه، سيقوم النظام بتحديث بيانات الجدول بالكامل!

عند التعامل مع قواعد بيانات حقيقية، نحتاج لتحديث سجلات بناءً على شروط دقيقة ومعقدة باستخدام AND و OR:

1. استخدام AND (تطابق جميع الشروط)

نستخدمها عندما نريد أن يتحقق كل من الشرطين معاً. (مثال: تحديث الراتب فقط إذا كان الموظف في قسم IT و راتبه الحالي أقل من 5000).

SQL
UPDATE employees SET salary = 5500.00 WHERE department = 'IT' AND salary < 5000;

2. استخدام OR (يكفي تحقق شرط واحد)

نستخدمها لتطبيق التغيير إذا تحقق أي شرط. (مثال: إضافة 500 دولار لأي موظف سواء كان في قسم الموارد البشرية أو المبيعات).

SQL
UPDATE employees SET salary = salary + 500 WHERE department = 'HR' OR department = 'Sales';

3. دمج AND مع OR (يجب استخدام الأقواس!)

الأقواس هنا تنقذك من كوارث برمجية. إذا أردنا زيادة رواتب الموظفين بنسبة 10% لمن يعملون في قسم IT أو المبيعات، ولكن بشرط أن يكون راتبهم أقل من 4000، يجب وضع OR داخل أقواس لتُنفذ أولاً.

SQL
UPDATE employees SET salary = salary * 1.10 WHERE (department = 'IT' OR department = 'Sales') AND salary < 4000;

4. البديل الأذكى لـ OR (استخدام IN)

بدلاً من تكرار OR للبحث في نفس العمود، نستخدم IN لتحديد قائمة من القيم.

SQL
UPDATE employees SET salary = salary + 200 WHERE department IN ('HR', 'Sales', 'IT');

5. دمج الشروط مع أدوات البحث (LIKE و BETWEEN)

للوصول لبيانات محددة جداً. (مثال: ترقية الموظف لقسم VIP إذا كان اسمه يبدأ بحرف "أ" و راتبه بين 3000 و 4000).

SQL
UPDATE employees SET department = 'VIP' WHERE name LIKE 'أ%' AND (salary BETWEEN 3000 AND 4000);

ثالثاً: الفرق الجوهري بين الحذف (DELETE, TRUNCATE, DROP)

جميعها تحذف، لكن طريقة العمل والنتيجة تختلف تماماً. لتبسيطها، تخيل أن جدول البيانات عبارة عن "دفتر ملاحظات":

طريقة DELETE (استخدام الممحاة) 🧽

أنت تمسك ممحاة وتمسح البيانات سطراً بسطر. يمكنك اختيار مسح سطر واحد أو عدة أسطر باستخدام WHERE. لأنها بطيئة وتسجل كل حركة، يمكنك التراجع عنها (Rollback). لا تقوم هذه العملية بتصفير عداد الأرقام التلقائية (ID).

طريقة TRUNCATE (تمزيق الصفحة) 📄

أنت لا تستخدم الممحاة، بل تمزق الصفحة المكتوبة بالكامل وتضع صفحة بيضاء جديدة. هي تحذف كل شيء دفعة واحدة وبسرعة فائقة، ولا تقبل استخدام WHERE. والأهم أنها تُصفر عداد الترقيم (ID) ليعود إلى رقم 1، ولا يمكن التراجع عنها.

طريقة DROP TABLE (الدمار الشامل) 🔥

أنت ترمي الدفتر بالكامل في النار. يتم مسح البيانات، وهيكل الجدول، والصلاحيات، وكل ما يتعلق به تماماً من قاعدة البيانات.

Introduction: Environment Setup

Before we start executing operations, let's create a table named employees to apply all the upcoming explanations and code examples:

SQL
CREATE TABLE employees ( id INT AUTO_INCREMENT PRIMARY KEY, name VARCHAR(100) NOT NULL, department VARCHAR(50), salary DECIMAL(10, 2) );
1

Part One: All INSERT Cases in MySQL

The INSERT statement is used to add new data to a table. In modern versions of MySQL, there are 8 different methods and use cases for insertion:

1. Standard Insert (Specifying Columns and Values)

This is the safest and clearest method. We specify the column names first, then pass the values in the exact same order.

SQL
INSERT INTO employees (name, department, salary) VALUES ('Ahmed', 'IT', 5000.00);

2. Shorthand Insert (Without Specifying Columns)

Here, we write the values directly without mentioning the column names.

⚠️

CRITICAL CONDITION: When using this method, the number of inserted values must exactly match the number of columns in the table, and in the exact same order. We use NULL for the id column so it auto-increments.

SQL
INSERT INTO employees VALUES (NULL, 'Khalid', 'HR', 4000.00);

3. Bulk Insert (Multiple Rows)

To improve database performance and save time, you can insert multiple records at once in a single query.

SQL
INSERT INTO employees (name, department, salary) VALUES ('Sarah', 'HR', 4500.00), ('Omar', 'Sales', 4800.00);

4. Inserting Using the SET Method

This method is specific to MySQL. It is very elegant and easy to read, as it looks very similar to an UPDATE statement.

SQL
INSERT INTO employees SET name = 'Mahmoud', department = 'IT', salary = 6000.00;

5. Copying from Another Table (INSERT INTO ... SELECT)

We use this when we want to take data from one table and insert it into another (e.g., for archiving).

SQL
INSERT INTO employees_archive (name, department, salary) SELECT name, department, salary FROM employees WHERE department = 'Sales';

6. Safe Insert Ignoring Errors (INSERT IGNORE)

If you try to insert an employee that already exists (e.g., has the same Primary Key ID), the system won't stop or throw an error. Instead, it will ignore that specific row and continue inserting the rest of the records.

SQL
INSERT IGNORE INTO employees (id, name, department) VALUES (1, 'Ahmed', 'IT');

7. Insert or Update (ON DUPLICATE KEY UPDATE)

Also known as an "Upsert". If the record doesn't exist, it will be created. If it already exists, the system will update it with your new data.

SQL
INSERT INTO employees (id, name, salary) VALUES (1, 'Ahmed', 5500.00) ON DUPLICATE KEY UPDATE salary = 5500.00;

8. Inserting Default Values Only

If all columns in your table have a DEFAULT value set, you can insert a new row relying entirely on those default values.

SQL
INSERT INTO employees () VALUES ();

Part Two: UPDATE and Complex Conditions

🚨

CRITICAL WARNING: Always use a WHERE clause with the UPDATE statement. If you don't, the system will update every single row in the entire table!

When dealing with real databases, you often need to update records based on precise and complex conditions using AND and OR:

1. Using AND (All conditions must be met)

Used when both conditions must be true simultaneously. (Example: Update the salary ONLY IF the employee is in the IT department AND their current salary is less than 5000).

SQL
UPDATE employees SET salary = 5500.00 WHERE department = 'IT' AND salary < 5000;

2. Using OR (At least one condition must be met)

Used to apply the change if any of the conditions are true. (Example: Give a $500 bonus to any employee who is in HR OR Sales).

SQL
UPDATE employees SET salary = salary + 500 WHERE department = 'HR' OR department = 'Sales';

3. Combining AND with OR (Parentheses are Mandatory!)

Parentheses save you from logical disasters. If we want to give a 10% raise to employees in IT or Sales, BUT only on the condition that their salary is less than 4000, we MUST put the OR condition inside parentheses so it gets evaluated first.

SQL
UPDATE employees SET salary = salary * 1.10 WHERE (department = 'IT' OR department = 'Sales') AND salary < 4000;

4. The Smarter Alternative to OR (Using IN)

Instead of repeating OR multiple times to check the same column, we use IN to specify a list of acceptable values.

SQL
UPDATE employees SET salary = salary + 200 WHERE department IN ('HR', 'Sales', 'IT');

5. Combining Conditions with Search Operators (LIKE & BETWEEN)

Used to target very specific data. (Example: Promote an employee to the VIP department if their name starts with the letter "A" AND their salary is between 3000 and 4000).

SQL
UPDATE employees SET department = 'VIP' WHERE name LIKE 'A%' AND (salary BETWEEN 3000 AND 4000);

Part Three: The Core Difference Between Deletions (DELETE, TRUNCATE, DROP)

All three commands remove things, but how they work and the final results are entirely different. To simplify it, imagine your database table is a "Notebook":

The DELETE Method (The Eraser) 🧽

You are holding an eraser and rubbing out data row by row. You can choose to erase one line or multiple lines using WHERE. Because it is slow and logs every single action, you can undo it (Rollback). This operation does NOT reset the auto-increment counter (ID).

The TRUNCATE Method (Tearing out the page) 📄

You don't use the eraser; instead, you rip the entire written page out and replace it with a fresh blank page. It deletes everything at once at lightning speed, and it does NOT accept a WHERE clause. Most importantly, it resets the auto-increment counter (ID) back to 1, and it cannot be undone.

The DROP TABLE Method (Total Destruction) 🔥

You throw the notebook into the fire. The data, the table structure, the permissions, and everything related to it are wiped entirely from the database.
