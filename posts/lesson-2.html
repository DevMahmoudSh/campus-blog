تشغيل خادم MySQL (MariaDB) داخل Termux

دليل عملي ومنهجي لإعداد وتشغيل بيئة خادم MySQL (MariaDB) داخل تطبيق Termux، مقسماً حسب المراحل التشغيلية مع تفصيل أوامر الطرفية (Bash) واستعلامات قاعدة البيانات (SQL).

💾

المتطلبات وسعة التخزين (Disk Usage)

البيان الحجم التقريبي الغرض
حجم حزم التحميل (Download) ~ 40 ميجابايت الأرشيفات المضغوطة للحزم
المساحة بعد التثبيت (Extracted) ~ 160 - 200 ميجابايت الملفات التنفيذية والمكتبات
المساحة الموصى بها كحد أدنى 500 ميجابايت لاستيعاب ملفات المحركات، الجداول، وملفات السجلات (Logs)
1

المرحلة الأولى: تجهيز البيئة وتثبيت الخادم

تحديث مستودعات الحزم

تحديث الفهارس وترقية البرمجيات القائمة لتفادي مشاكل توافق المكتبات المشتركة: 

pkg update && pkg upgrade -y

تثبيت حزمة MariaDB

في أنظمة Linux وTermux، تُعد حزمة MariaDB هي المعيار البديل والمطابق لمحرك MySQL: 

pkg install mariadb -y
2

المرحلة الثانية: تهيئة النظام وتشغيل الخدمة

بناء الجداول الأساسية للنظام (تُنفذ لمرة واحدة فقط)

يقوم هذا الأمر بإنشاء دليل البيانات وافتتاح جداول الصلاحيات الخاصة بالمستخدم root: 

mariadb-install-db

تشغيل خادم قاعدة البيانات في الخلفية

يتم استخدام سكربت mysqld_safe متبوعاً بالرمز & ليعمل الخادم دون قفل واجهة الأوامر الحالية: 

mysqld_safe &
💡

ملاحظة تطبيقية: عند ظهور مخرجات الإقلاع وعبارة mysqld_safe Starting mysqld daemon...، اضغط على زر Enter للعودة إلى سطر الأوامر.

3

المرحلة الثالثة: الاتصال وإدارة قواعد البيانات (SQL)

تسجيل الدخول إلى موجه الأوامر التفاعلي

افتراضياً في Termux، يدخل حساب المشرف بدون كلمة مرور: 

mysql -u root

(سيتغير سطر الأوامر إلى MariaDB [(none)]>)

تنفيذ أول سيناريو تجريبي (إنشاء قاعدة بيانات، جدول، وسجلات)

انسخ الاستعلامات التالية بالترتيب: 


-- 1. إنشاء قاعدة بيانات تجريبية باسم university_db
CREATE DATABASE university_db;

-- 2. عرض قواعد البيانات للتأكد من إنشائها
SHOW DATABASES;

-- 3. تفعيل استخدام قاعدة البيانات الجديدة
USE university_db;

-- 4. إنشاء جدول للطلاب بحقول المعرف والاسم والمعدل التراكمي
CREATE TABLE students (
    student_id INT AUTO_INCREMENT PRIMARY KEY,
    full_name VARCHAR(100) NOT NULL,
    major VARCHAR(50),
    gpa DECIMAL(3,2)
);

-- 5. عرض بنية الجدول والتحقق من الحقول
DESCRIBE students;

-- 6. إدراج بيانات تجريبية
INSERT INTO students (full_name, major, gpa) 
VALUES ('محمود أحمد', 'Computer Science', 3.85);

-- 7. الاستعلام عن البيانات المضافة
SELECT * FROM students;
4

المرحلة الرابعة: الإنهاء وإيقاف العمليات

الخروج من موجه SQL

للعودة إلى طرفية Termux العادية: 

EXIT;

إيقاف الخادم بشكل كامل

للحفاظ على موارد بطارية ومعالج الجهاز بعد الانتهاء من العمل المخبري: 

killall mysqld mysqld_safe
