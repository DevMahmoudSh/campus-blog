1

الأسماء المستعارة في MySQL (MySQL Aliases)

تُستخدم الأسماء المستعارة (Aliases) لإعطاء جدول أو عمود في جدول اسماً مؤقتاً لتسهيل قراءة مخرجات الاستعلام. في MySQL، نستخدم علامات الاقتباس المائلة (Backticks `) للأسماء التي تحتوي على مسافات.

الصيغة العامة (Syntax)

SQL
SELECT column_name AS `alias_name` FROM table_name;

مثال (العمليات الحسابية)

استخراج السعر شامل الضريبة وإعطاؤه اسماً واضحاً:

SQL
SELECT `product_name` AS `اسم المنتج`, `price` AS `السعر الأصلي`, (`price` * 1.15) AS `السعر شامل الضريبة` FROM `products`;
2

دوال دمج النصوص في MySQL (CONCAT و CONCAT_WS)

تُستخدم دالة CONCAT() لدمج قيمتين أو أكثر معاً.

الصيغة العامة (Syntax)

SQL
SELECT CONCAT(column1, column2, ...) FROM table_name;
⚠️

ملاحظة هامة (Note): في MySQL، إذا كانت إحدى القيم الممررة لدالة CONCAT تساوي NULL، فإن النتيجة بأكملها ستكون NULL.

مثال (مشكلة CONCAT)

إذا لم يكن للموظف اسم أوسط (mid_name = NULL)، ستكون النتيجة كاملة فارغة!

SQL
SELECT CONCAT(`first_name`, ' ', `mid_name`, ' ', `last_name`) AS `الاسم الثلاثي` FROM `users`;

الحل: استخدام CONCAT_WS()

دالة CONCAT_WS تعني (With Separator). تقوم بتحديد فاصل، وتقوم الدالة بتجاهل أي قيم NULL تلقائياً.

SQL
SELECT CONCAT_WS(' ', `first_name`, `mid_name`, `last_name`) AS `الاسم الكامل` FROM `users`;
3

تعليمة MySQL SELECT DISTINCT

تُستخدم الكلمة المفتاحية DISTINCT لاسترجاع القيم المختلفة (الفريدة) فقط وحذف التكرار.

الصيغة العامة (Syntax)

SQL
SELECT DISTINCT column_name1, column_name2 FROM table_name;

مثال 1 (عمود واحد)

جلب قائمة الدول التي تم الشحن إليها دون تكرار اسم الدولة:

SQL
SELECT DISTINCT `shipping_country` FROM `orders`;

مثال 2 (عدة أعمدة)

سيقوم MySQL بجلب "التركيبة الفريدة" للعمودين معاً:

SQL
SELECT DISTINCT `city`, `department` FROM `branches`;
4

مُعامل MySQL LIKE

يُستخدم المُعامل LIKE في جملة WHERE للبحث عن نمط معين (Pattern) داخل عمود.

  • % تمثل صفر، أو واحد، أو عدة أحرف.
  • _ تمثل حرفاً واحداً فقط.
💡

ملاحظة (Note): افتراضياً في MySQL، البحث باستخدام LIKE غير حساس لحالة الأحرف (Case-Insensitive).

الصيغة العامة (Syntax)

SQL
SELECT column_name(s) FROM table_name WHERE column_name LIKE pattern;

مثال 1 (البحث العادي)

هذا الاستعلام سيجلب info@gmail.com وأيضاً INFO@GMAIL.COM:

SQL
SELECT `email` FROM `users` WHERE `email` LIKE '%@gmail.com';

مثال 2 (البحث الحساس للأحرف - Case Sensitive)

نستخدم الكلمة المفتاحية BINARY لإجبار MySQL على مطابقة حالة الأحرف تماماً:

SQL
SELECT `product_name` FROM `products` WHERE `product_code` LIKE BINARY 'Pro%';
5

مُعامل MySQL BETWEEN

يختار المُعامل BETWEEN القيم التي تقع ضمن نطاق معين (شاملاً قيمتي البداية والنهاية).

الصيغة العامة (Syntax)

SQL
SELECT column_name(s) FROM table_name WHERE column_name BETWEEN value1 AND value2;

مثال (الأرقام)

SQL
SELECT `car_model`, `engine_cc` FROM `vehicles` WHERE `engine_cc` BETWEEN 1600 AND 2000;
💡

نصيحة للمحترفين (Pro Tip): عند استخدام BETWEEN مع حقول التواريخ والوقت DATETIME في MySQL، كن حذراً. نهاية النطاق '2023-10-31' تُحسب كـ '2023-10-31 00:00:00'. الطريقة الأسلم للتواريخ هي استخدام الأكبر من والأصغر من:

SQL
SELECT * FROM `orders` WHERE `created_at` >= '2023-10-01 00:00:00' AND `created_at` <= '2023-10-31 23:59:59';
6

مُعامل MySQL IN

يسمح لك المُعامل IN بتحديد قيم متعددة في جملة WHERE (وهو اختصار لشروط OR المتعددة).

الصيغة العامة (Syntax)

SQL
SELECT column_name(s) FROM table_name WHERE column_name IN (value1, value2, ...);

مثال (IN و NOT IN)

SQL
-- جلب الطلبات المكتملة والمعلقة SELECT `order_id`, `status` FROM `orders` WHERE `status` IN ('Completed', 'Pending'); -- استبعاد أقسام معينة SELECT `name` FROM `employees` WHERE `department` NOT IN ('Executive', 'HR');
🚀

ميزة متقدمة (Advanced Feature): يدعم MySQL مطابقة المتجهات (Tuple Matching)، مما يسمح بفحص عدة أعمدة معاً:

SQL
SELECT `name` FROM `employees` WHERE (`department`, `role`) IN (('IT', 'Manager'), ('Sales', 'Specialist'));
7

الكلمة المفتاحية MySQL ORDER BY

تُستخدم لترتيب مجموعة النتائج ترتيباً تصاعدياً ASC (الافتراضي) أو تنازلياً DESC.

الصيغة العامة (Syntax)

SQL
SELECT column_name(s) FROM table_name ORDER BY column_name1 ASC|DESC;

مثال 1 (ترتيب متعدد)

SQL
SELECT `student_name`, `grade`, `gpa` FROM `students` ORDER BY `grade` ASC, `gpa` DESC;
🎩

خدعة MySQL (MySQL Trick): MySQL لا تدعم تعليمة NULLS LAST. لدفع القيم الفارغة (NULL) إلى أسفل الجدول، نقوم بتقييم الشرط أولاً:

SQL
SELECT `username`, `expiry_date` FROM `subscriptions` ORDER BY (`expiry_date` IS NULL) ASC, `expiry_date` ASC;
8

تعليمة MySQL LIMIT

تُستخدم LIMIT لتحديد الحد الأقصى لعدد السجلات التي سيتم إرجاعها. في MySQL، يمكنك دمجها برقم التخطي (OFFSET) مباشرةً في جملة واحدة.

الصيغة العامة (Syntax)

SQL
-- الصيغة المختصرة الخاصة بـ MySQL SELECT column_name(s) FROM table_name LIMIT offset, count;

مثال 1 (استخدام LIMIT المختصر)

تخطي أول 15 مقال، وعرض الـ 5 مقالات التالية:

SQL
SELECT `title`, `publish_date` FROM `articles` ORDER BY `publish_date` DESC LIMIT 15, 5;
⚡

نصيحة أداء (Performance Tip): في الجداول الضخمة، استخدام LIMIT مع أرقام OFFSET كبيرة (مثل مليون) يُبطئ قاعدة البيانات جداً. الطريقة الاحترافية هي استخدام آخر مُعرف (ID) تم عرضه:

SQL
-- أسرع بكثير من استخدام OFFSET SELECT `id`, `username` FROM `users` WHERE `id` > 50200 ORDER BY `id` ASC LIMIT 20;

MySQL Aliases

SQL aliases are used to give a table, or a column in a table, a temporary name. This makes column names more readable. In MySQL, it is a best practice to use backticks (`) to wrap column names or aliases, especially if they contain spaces.

Syntax

SQL
SELECT column_name AS `alias_name` FROM table_name;

Example (Mathematical Calculation)

Calculating the price with tax and giving it a readable name:

SQL
SELECT `product_name` AS `Product Name`, `price` AS `Original Price`, (`price` * 1.15) AS `Price with Tax` FROM `products`;
2

MySQL String Functions (CONCAT & CONCAT_WS)

The CONCAT() function adds two or more expressions together.

Syntax

SQL
SELECT CONCAT(column1, column2, ...) FROM table_name;
⚠️

Important Note: In MySQL, if any of the values passed to the CONCAT function is NULL, the entire result will become NULL!

Example (The CONCAT Trap)

If an employee has no middle name (mid_name = NULL), the entire full name will be completely empty (NULL).

SQL
SELECT CONCAT(`first_name`, ' ', `mid_name`, ' ', `last_name`) AS `Full Name` FROM `users`;

The Solution: Using CONCAT_WS()

CONCAT_WS stands for "With Separator". You define a separator first, and the function will automatically ignore any NULL values safely.

SQL
SELECT CONCAT_WS(' ', `first_name`, `mid_name`, `last_name`) AS `Safe Full Name` FROM `users`;
3

MySQL SELECT DISTINCT Statement

The SELECT DISTINCT statement is used to return only distinct (different) values.

Syntax

SQL
SELECT DISTINCT column_name1, column_name2 FROM table_name;

Example 1 (Single Column)

Get a list of countries we shipped to, without repeating the country names:

SQL
SELECT DISTINCT `shipping_country` FROM `orders`;

Example 2 (Multiple Columns)

MySQL will look for the unique combination of both columns:

SQL
SELECT DISTINCT `city`, `department` FROM `branches`;
4

MySQL LIKE Operator

The LIKE operator is used in a WHERE clause to search for a specified pattern in a column.

  • % represents zero, one, or multiple characters.
  • _ represents a single character.
💡

Note: By default, string comparisons using LIKE in MySQL are case-insensitive (A = a).

Syntax

SQL
SELECT column_name(s) FROM table_name WHERE column_name LIKE pattern;

Example 1 (Default Case-Insensitive)

This will match info@gmail.com, INFO@GMAIL.COM, and InFo@gmail.com:

SQL
SELECT `email` FROM `users` WHERE `email` LIKE '%@gmail.com';

Example 2 (Case-Sensitive Search)

Use the BINARY keyword to force MySQL to match the exact uppercase and lowercase letters:

SQL
-- Will only match if "Pro" starts with a capital 'P' SELECT `product_name` FROM `products` WHERE `product_code` LIKE BINARY 'Pro%';
5

MySQL BETWEEN Operator

The BETWEEN operator selects values within a given range. The values can be numbers, text, or dates. The range is inclusive.

Syntax

SQL
SELECT column_name(s) FROM table_name WHERE column_name BETWEEN value1 AND value2;

Example (Numbers)

SQL
SELECT `car_model`, `engine_cc` FROM `vehicles` WHERE `engine_cc` BETWEEN 1600 AND 2000;
💡

Pro Tip (The DATETIME Trap): Be careful when using BETWEEN with DATETIME columns in MySQL. The end date '2023-10-31' is evaluated as '2023-10-31 00:00:00', meaning you will lose all orders placed later on that day. The safest way for dates is using >= and <=:

SQL
SELECT * FROM `orders` WHERE `created_at` >= '2023-10-01 00:00:00' AND `created_at` <= '2023-10-31 23:59:59';
6

MySQL IN Operator

The IN operator allows you to specify multiple values in a WHERE clause (it is a shorthand for multiple OR conditions).

Syntax

SQL
SELECT column_name(s) FROM table_name WHERE column_name IN (value1, value2, ...);

Example (IN and NOT IN)

SQL
-- Get completed and pending orders SELECT `order_id`, `status` FROM `orders` WHERE `status` IN ('Completed', 'Pending'); -- Exclude specific departments SELECT `name` FROM `employees` WHERE `department` NOT IN ('Executive', 'HR');
🚀

Advanced Feature: MySQL supports Tuple Matching, allowing you to check multiple columns simultaneously:

SQL
SELECT `name` FROM `employees` WHERE (`department`, `role`) IN (('IT', 'Manager'), ('Sales', 'Specialist'));
7

MySQL ORDER BY Keyword

The ORDER BY keyword is used to sort the result-set in ascending (ASC) or descending (DESC) order.

Syntax

SQL
SELECT column_name(s) FROM table_name ORDER BY column_name1 ASC|DESC;

Example 1 (Multi-level Sort)

SQL
SELECT `student_name`, `grade`, `gpa` FROM `students` ORDER BY `grade` ASC, `gpa` DESC;
🎩

MySQL Trick: Unlike some databases, MySQL does not support the NULLS LAST syntax natively. To push NULL values to the bottom of your sorted list, evaluate the condition first:

SQL
-- Subscriptions with NULL expiry_date will appear at the very bottom SELECT `username`, `expiry_date` FROM `subscriptions` ORDER BY (`expiry_date` IS NULL) ASC, `expiry_date` ASC;
8

MySQL LIMIT Clause

The LIMIT clause is used to specify the number of records to return. MySQL provides a unique shorthand syntax for pagination: LIMIT offset, count.

Syntax

SQL
-- MySQL shorthand syntax SELECT column_name(s) FROM table_name LIMIT offset, count;

Example 1 (Using Shorthand LIMIT)

Skip the first 15 articles, and return the next 5:

SQL
SELECT `title`, `publish_date` FROM `articles` ORDER BY `publish_date` DESC LIMIT 15, 5;
⚡

Performance Tip: In huge tables, using LIMIT with a very large OFFSET (e.g., a million) is extremely slow. The professional way (Keyset Pagination) is to use the last seen ID:

SQL
-- Much faster than using a huge OFFSET SELECT `id`, `username` FROM `users` WHERE `id` > 50200 ORDER BY `id` ASC LIMIT 20;
